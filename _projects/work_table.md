# Work Table — shop desk for project builds

I built a work table to serve as a reliable desk for many projects on this site. The first version used wood beams, dowels, nuts and plates. Later, I designed a second version using 30x30 square metal tube; by cutting channels and adding hinges, the table folds flush when not in use.

## Version 1 — Wooden frame (beams, dowels, nuts)

Goals: fast to build, rigid enough for hand tools and assembly work, and sized to my workspace.

## Lessons learned

- Wood version: simple and quick, but dimensional stability and fastener loosening required regular checks.
- Metal version: more fabrication effort (cutting channels, hinge alignment), but better stiffness and fold-flat convenience.
- Plan wall anchors and hinge axes early; ensure clearances when folded.

This table underpins many of the project builds on this site and the fold-flat feature keeps the workspace flexible.
